# Support

Orvia is pre-1.0 and maintained by one person. Support is best-effort and there is no response-time guarantee.

- **Bugs and feature requests:** open a [GitHub issue](https://github.com/9uiLe/orvia/issues/new/choose) using the templates.
- **Questions:** open a GitHub issue. Check the README and `docs/` first.
- **Security vulnerabilities:** do not open an issue. Follow [SECURITY.md](SECURITY.md).

Never include secrets, credentials, tokens, or private source code in an issue.
